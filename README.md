# agent-plugins

Curated public distribution repository for agent plugins maintained by
WSH95.

## Plugins

- `project-steward/` — cross-agent project stewardship plugin for Claude
  Code, Codex, and other coding agents.

## Install

Each plugin directory contains the generated install payloads and
marketplace metadata needed by its supported agent platforms. See the
plugin's own README or install notes for exact commands.
